# Footer Specification

## Overview
- **Target file:** `src/components/Footer.tsx`
- **Interaction model:** static + hover

## DOM Structure
footer > div.max-w-7xl > div.grid.md:grid-cols-3 [col1: brand + desc] [col2: quick links] [col3: about + social + app badges]
copyright-bar

## Columns
1. **Brand:** الليرة اليوم + description text
2. **Quick Links:** أسعار الصرف, الذهب, الفضة, العملات الرقمية, الطاقة, الأخبار
3. **About:** أعلن معنا, اتصل بنا, API
   **Social:** Facebook, WhatsApp, Telegram (brand colors on hover)
   **App badges:** App Store + Google Play
